# Dicionário de dados

- **produtos.csv**: cadastro dos produtos, categoria, custo, preço e estoque mínimo.
- **fornecedores.csv**: cadastro fictício de fornecedores.
- **compras.csv**: itens comprados, data, fornecedor, quantidade e custo unitário.
- **movimentacoes_estoque.csv**: entradas e saídas; estoque inicial é representado por entradas com origem `ESTOQUE_INICIAL`.
- **vendas.csv**: itens vendidos, data, quantidade e valor unitário de venda.

Datas cobrem 2025. Valores e operações foram gerados artificialmente para fins didáticos.
